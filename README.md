# Uzm. Psk. Ayhan Altaş - Web Sitesi & Teklif Dosyası

Bu proje, Uzman Klinik Psikolog & Psikoterapist **Ayhan Altaş** için özel olarak hazırlanmış, yapay zeka şablonlarından uzak ("anti-slop"), bilimsel klinik ciddiyete ve sıcak bir terapi diline sahip modern web deneyimidir.

---

## 📁 Dosya Yapısı

- `index.html`: Tamamen semantik HTML5, erişilebilir ve duyarlı yapı.
- `styles.css`: Özel tasarım sistemi (Newsreader serif + Albert Sans, soft structuralism / double-bezel kartlar, sıfır yapay gradyan, sıfır sahte çizgi).
- `app.js`: İnteraktif "Klinik Terapi Yönelim ve İhtiyaç Keşfi" aracı, mobil menü ve akordiyon SSS modülü.
- `TEKLIF_EPOSTASI.md`: Ayhan Bey'e gönderilmek üzere hazırlanmış profesyonel e-posta taslağı.
